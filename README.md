# Smart Study Planner
A console program to help students plan, track and analyze study sessions.

Features:
- Add study session (subject, topic, date, duration)
- View all sessions with classification (Short <30 mins, Medium 30-90 mins, Long >90 mins)
- Search by subject
- Statistics (total hours, per subject, weakest subject, longest session)
- Save/load to study_log.txt using file handling
- Loop, if/elif/else, break, continue, try/except, functions

How to run:
python study_planner.py
